# Cubik

Cubik es un juego de plataformas 2D inspirado en Geometry Dash, donde controlas un cubo que debe saltar obstáculos y recolectar monedas. Incluye múltiples niveles, modos de juego (cube, ship, ball, ufo, wave, robot), sistema de logros, editor de niveles y efectos visuales avanzados.

## Requisitos para Ejecutar

- **Python 3.x** (probado con 3.11)
- **Librerías requeridas:**
  - `tkinter` (incluido en Python estándar)
  - `pygame`
  - `numpy`
  - `collections` (incluido en Python estándar)

## Cómo Ejecutar

1. Instala las dependencias: `pip install pygame numpy`
2. Ejecuta: `python Cubik.py`
